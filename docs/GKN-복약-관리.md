# GKN 복약 관리 — 시간표·체크·안약 순서·알림 (2026-11-28)

## 무엇이 바뀌었나
기존 GKN은 **복약 안내문 생성기**였습니다. 이제 처방을 **시간대 표**로 바꿔 보호자가 시간마다 체크하고, 안약은 **순서와 간격**을 지켜 넣게 합니다.

| 기능 | 내용 |
|---|---|
| 약 종류 | 내복약 · 안약 · 귀약 · 연고 · 주사(병원) · **보조제** |
| 좌/우 | 안약·귀약은 좌안/우안/양안, 좌이/우이/양이 |
| 시간표 | 1회 09:00 · 2회 08:00/20:00 · 3회 08:00/14:00/20:00 · 4회 07:00/12:00/17:00/22:00 — 칸마다 수정 가능 |
| 한 표 | 같은 시간대의 내복약·보조제·안약이 한 카드에 (예: 08:00 — 31번 1정 + 유산균 1포) |
| 안약 순서 | 제형(액→현탁액→겔→연고)과 ‘순서’ 번호로 정렬. 단계마다 체크, 사이에 **5분 간격 카운트다운** |
| 체크 | `먹었어요/넣었어요/발랐어요` → **시각이 남고 덮어쓰지 않음**. 되돌리기 가능 |
| 놓친 약 | 시간이 1시간 넘게 지난 미체크는 **빨간 카드 + 안내**(두 배로 먹이지 말고 병원에 전화 031-715-7119) |
| 이행률 | 오늘(예정/완료) + 최근 7일 % |
| 사진·색 | 약마다 뚜껑·라벨 색 태그(주황·파랑 등 10색)와 사진. 표·체크 화면에 작게 보이고 누르면 크게 |
| 원장님 코멘트 | “31번 하루 두 번 / 33번 안약 하루 네 번 우안 (현탁액)”을 붙여넣으면 표가 채워짐 |
| 보호자 링크 | `gkn.html?pet=아이&guardian=보호자` — 그 아이 것만. 서버에서 처방을 받아 옴 |
| 알림 | ① 웹 알림(권한 허용 시, 앱 열어 둔 동안) ② **ICS 캘린더 파일**(앱을 닫아도 오는 확실한 길) ③ 홈 화면 추가(PWA) |
| 기록 | 이 기기(localStorage) + `GCN_실시간_데이터` 시트 `복약` 탭 |

## 안약 순서·간격의 근거
- **Merck Veterinary Manual**, *Routes of Administration for Ocular Medications in Animals* (N. Whelan, DACVO, 2024 개정): "A 5-minute interval between topical drugs is recommended… Solutions and suspensions should be applied before gels and ointments."
- **ACVO public**, *Tips for Eye Medication*: 점성 순서(방울→겔→연고), 서로 최소 5~10분.
- **University of Tennessee UTCVM 안과**, *Eye Drop Dosing Chart*: 5~10분 간격, 연고는 마지막, 하루 횟수는 같은 간격으로.

## 시트 `복약` 탭 (19열)
`접수시각 · 보호자 · 아이 · 처방일 · 복약일 · 시간대 · 약이름 · 종류 · 좌우 · 용량 · 횟수/일 · 일수 · 체크시각 · 이행여부 · 뚜껑색 · 사진링크 · 비고 · 처방상세 · 접수ID`

- 한 줄 = 한 아이 · 한 날 · 한 시간대 · 한 약.
- 같은 키(아이/복약일/시간대/약이름/종류/좌우)면 새 줄을 만들지 않고 **체크만 채웁니다**.
- `처방상세`에 약 정의(JSON)가 들어 있어 보호자 링크가 처방을 되살립니다.
- 사진은 드라이브 `GKN_복약사진/{아이}/`에 올리고 링크를 `사진링크`에 적습니다(병원 계정 비공개).

- 배포: 웹 앱 · 실행 나 · 액세스 모든 사용자 · **v2**
- URL: `https://script.google.com/macros/s/AKfycbzsszvQjIS49BiP3RuA1gO02OO1rE5HO5loG41lVPGXZn5Fvzsf9M2a8LTBX408PdFbJg/exec`
- 요청: `POST {action:'med_submit'|'med_photo'}`, `GET ?action=med_get&pet=&guardian=`
- 코드 원본: `docs/gkn-med-server.gs`
- **별도 프로젝트로 만든 이유**: GBN(미용)·GWN(체중)이 쓰는 기존 프로젝트의 `doPost`는 각자 정해진 분기만 받아서, 함수를 새로 넣어도 HTTP로 부를 수 없습니다. 그 프로젝트를 고치면 동시에 배포 중인 다른 작업과 부딪힙니다. 그래서 GWN이 한 것과 같은 방식으로 **GKN 전용 프로젝트**를 만들었습니다(기존 배포 URL은 그대로).

## 알림의 정확한 한계
- **웹 알림**: 폰 설정에서 알림을 허용하고 홈 화면에 추가해야 옵니다. 앱을 완전히 닫으면 오지 않을 수 있습니다. 아이폰은 홈 화면에 추가한 PWA에서만 됩니다(구버전 iOS 불가).
- **ICS**: 앱이 꺼져 있어도 오는 유일하게 믿을 만한 길. 6개 시간대 × 7일 반복, 정시 알림 1개.
- **앱을 닫아도 오는 푸시(FCM)**: 이번에 붙이지 못했습니다. Firebase 콘솔이 **계정 2단계 인증**을 요구해 막혔습니다. 다음 단계 준비물은 아래.

### FCM 다음 단계 (무료)
1. 병원 구글 계정에 2단계 인증(2SV) 켜기 — 희진 님 폰 필요.
2. Firebase 프로젝트 생성 + 웹 앱 등록 → `apiKey·projectId·messagingSenderId·appId`.
3. Cloud Messaging → **웹 푸시 인증서(VAPID) 키 쌍** 발급.
4. 서비스 계정 키(JSON) 발급 → Apps Script 스크립트 속성에 넣기.
5. 페이지에 Firebase SDK + `firebase-messaging-sw.js`, 기기 토큰을 시트 `복약기기` 탭에 저장.
6. Apps Script 시간 트리거(5분)가 오늘 시간대표를 보고 FCM HTTP v1로 발송.
