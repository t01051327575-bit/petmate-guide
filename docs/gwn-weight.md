## 화면 기능

1. **아이와 목표** — 목표 `체중 조절·알러지 관리·피부·소화·관절`. 알러지 관리면 먹은 것 사진이 필수.
2. **체중 기록** — 날짜·체중·목표·병원 확인 BCS. 그래프는 체중 선 + 간식 막대.
3. **식이 관리** — ① 운동 시작/완료 타이머(시작·종료 시각·분, 하루 여러 번, 직접 입력도 가능) ② 사료 종류·이름·급여량·횟수 ③ 간식 여부·양 ④ 오늘 먹은 것 사진 ⑤ 알러지 노출 ⑥ 메모.
4. **칭찬** — 연속 기록 1·2·3·7·14·30일에 칭찬 카드. **오늘 도달한 가장 높은 단계 하나만** 남기고 이력은 덮어쓰지 않는다. 끊겨도 벌주는 문구 없음("다시 시작하면 됩니다").
5. **위에서 찍는 BCS 사진** — 카메라 미리보기 위에 머리·꼬리 프레임 오버레이 → 촬영본에서 실루엣을 찾아 갈비(가장 넓은 곳)·허리(가장 좁은 곳) 선을 자동 배치 → 손으로 끌어 조정 → 허리/갈비 비율로 BCS 추정. 사진은 날짜별로 쌓이고 두 날짜를 골라 나란히 비교한다.
6. **한 달 요약** — 운동한 날·기록한 날·운동 합계·하루 평균·간식 횟수·먹은 것 사진 수·체중 변화·받은 칭찬 수.
7. **보호자에게 같이 보내기** — 아이·보호자·목표가 미리 세팅된 링크와 카톡 문구(400자, 빈 줄)를 만들어 두기만 한다. **발송은 하지 않는다.**

## BCS 추정 근거 (추정값이며 확정 아님)

- 근거: Gant P. et al., *Can you estimate body composition in dogs from photographs?* BMC Vet Res 2016;12:19 — 표준 등쪽(위에서) 사진에서 잰 **복부폭/흉곽폭(A:T) 비율**의 구분점: 적정 <0.77, 과체중 0.77~0.87, 비만 >0.87 (연구진이 BCS·체지방률에 맞춰 주관적으로 정한 값).
- 이 페이지는 그 세 구간을 9점 척도로 펼쳐 쓴다: <0.68→3, <0.72→4, <0.77→5, <0.82→6, <0.87→7, ≥0.87→8.
- 검증된 공식이 아니고, 마른 쪽(BCS 1~3)은 비율로 구분이 어렵다. 화면에 항상 **"털 길이·체형에 따라 다르게 보일 수 있습니다. 정확한 판정은 진료실에서 원장님 확인이 필요합니다."** 를 띄우고, 원장님 확정값(`병원 확인 BCS`)이 있으면 그것이 기준이라고 표시한다.

## 남은 일

- **원장님 확정 BCS 입력 UI**: 지금은 보호자 페이지에서 직접 고른다. 진료실에서 입력하는 화면은 GCN 쪽 몫.
- **GCN 카드 표시**: GCN이 `체중`·`식이관리` 탭을 읽어 카드에 최근 체중·추이·운동·간식 한 줄을 붙이는 것은 아직 안 했다(당시 GCN을 다른 작업이 수정 중).
- **GCN 코멘트 → 목표 자동 제안**: 진료 코멘트에 식이·사료·체중·운동·알러지·피부·소화 표현이 있으면 목표를 자동 제안하는 것도 GCN 몫. 링크 규격은 위에 맞춰 두었다.
- GTN 문구에 이 링크를 넣는 것은 아직 반영 전이다(문구 양식은 GWN 화면에서 복사 가능).
