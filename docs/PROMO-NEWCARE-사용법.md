# PROMO · NEWCARE 사용법 — 주 1회 홍보와 신제품 설명

> 만든 날: 2026-11-28 · 진심경영멘토 유희진 · 경영부원장
> 대상: 굿모닝펫동물병원 원무·진료팀

## 한 줄 요약

- **PROMO** (`promo.html`) — 이번 주 잘 나간 품목 하나로 ① 카톡 문구 ② 네이버 블로그 초안 ③ 인스타 카드 3장 ④ FAQ·JSON-LD를 한 번에 만듭니다.
- **NEWCARE** (`newcare.html`) — 보호자가 하는 증상 언어를 고르면 ① 확인 질문 ② 설명 ③ 다음 단계, 직원이 읽는 문장, 400자 카톡, GQN 퀴즈까지 나옵니다.

## PROMO — 주 1회 흐름

1. GAN·경영대장에서 **이번 주 잘 팔린 품목**을 확인합니다.
2. `promo.html`에서 품목을 붙여넣거나 소재를 고릅니다(리브렐라·구강·피부·심장사상충·노령견 검진·장 건강·고양이 관절, 또는 직접 입력).
3. 카톡 400자·블로그 600~900자·인스타 3장·FAQ를 확인합니다.
4. **실장님 승인 후**에만 카톡·블로그·인스타에 올립니다. 페이지는 초안만 만듭니다.
5. 매주 월요일 08:30에 초안 파일을 만들어 두는 스케줄이 따로 있습니다(발송 없음).

### 문구 규칙

- 효과·수치·비교를 새로 만들지 않습니다. 공식 자료에서 확인한 문장만 씁니다.
- 제품 설명에는 출처와 확인 날짜를 남깁니다.
- 끝에 "진단과 처방은 진료 후에 정해집니다" 고지를 유지합니다.
- 카톡은 앞뒤 따옴표 없이, 400자 이내, 문단마다 빈 줄. 긴 링크는 is.gd로 줄입니다.

## NEWCARE — 신제품이 들어왔을 때

1. 보호자가 실제로 하는 말을 고릅니다(다리가 아파요 · 계단에서 망설여요 · 피부가 가려워요 · 입 냄새 · 밥을 안 먹어요 · 소변 · 기침 · 고양이 다리).
2. 3단 설명을 그대로 읽습니다. 진단을 단정하지 않고, 보호자가 본 모습을 확인하는 질문으로 시작합니다.
3. 카톡은 400자로 보냅니다.
4. 직원 교육은 GQN 퀴즈 7문제(정답·해설 분리)로 합니다. 문제만 직원에게, 정답은 실장님께.
5. 새 제품은 [신제품·시술 추가]에 입력하면 같은 구조로 설명·카톡·퀴즈가 자동으로 만들어집니다(이 브라우저에 저장, JSON으로 이동 가능).
