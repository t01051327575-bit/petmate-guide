# GCN 적용 규칙 — 다른 병원에서 돌리려면 예약표에 이 칸이 있어야 한다

## 결론
GCN의 준비물은 **예약 엑셀 한 개**다. 다만 그 안에 **"이 예약이 무엇인지"** 를 가리키는 칸이 반드시 있어야 한다.

## 필수 칸 (최소 4개)
| 칸 | 예 | 없으면 |
|---|---|---|
| 보호자 이름 | 김보호 | 누구인지 모른다 |
| 아이 이름 | 누아 | 카드 제목이 안 뜬다 |
| 예약 시각 | 11/30 10:30 | 순서를 못 잡는다 |
| **예약 유형** | 진료 / 검사 / 수술 / 미용·백신 | **금식·준비 안내를 못 붙인다** |

## 예약 유형이 있어야 자동으로 붙는 것
| 유형 | 자동으로 붙는 안내 |
|---|---|
| **진료** | 내원 전 건강관리표(GHN) 링크, 진료 코멘트 3종(GTN) |
| **검사** | 검사 전 준비(금식·금수 여부), 검사실 12단계 루틴(GPN·자리 지도), 결과 해설(GDN) |
| **수술** | **금식·금수 시간**, 안정제·보호자 동의 안내, 수술실 제로 체크(GZN) |
| **미용·백신** | 미용 전 체크 링크(GBN), 백신 예정일(GYN) |

## 유형이 없을 때 대응 3단계
1. **예약 받을 때 유형 한 칸** — 원무과가 예약 잡을 때 진료/검사/수술/미용 중 하나만 고르게 한다. 가장 확실하고, 추가 비용 0원.
2. **예약 사유 텍스트로 추정** — '금식', '수술', '검사', '미용', '백신' 같은 단어가 사유란에 있으면 자동 분류하고, 확신이 낮은 건은 **'확인 필요'** 로 따로 표시한다.
3. **확인 필요 건만 사람이 확인** — 원무과가 아침에 한 번 훑는다. 추정을 사실처럼 쓰지 않는다.

## 원무과 예약 접수 기본 업무 (이것만 지키면 된다)

전화·카톡·내원으로 예약을 잡을 때 **아래 5칸을 채운다.** 그중 하나도 비우면 안 된다.

- [ ] ① 보호자 이름
- [ ] ② 아이 이름
- [ ] ③ 날짜·시간
- [ ] ④ **예약 유형 하나 고르기** — 진료 / 검사 / 수술 / 미용·백신
- [ ] ⑤ 한 줄 사유 (예: 다리 절뚝거림, 심장사상충 검사, 중성화, 목욕+발톱)

**유형을 고르는 순간 아래가 자동으로 준비된다.**
- 검사 → 금식·금수 여부와 준비물 안내
- 수술 → 금식·금수 시간과 보호자 동의 안내
- 미용 → 미용 전 체크 링크(GBN) 전달
- 진료 → 내원 전 건강관리표(GHN) 링크 안내

**규칙 한 줄: 유형이 안 정해졌으면 금식 안내를 보내지 않는다.** 잘못 보내면 아이가 하루 종일 굵는다. 모르면 원장님께 한 번 묻고 유형부터 정한다.

## 보호자 준비 요청이 원장님 뷰에 뜨는 조건

GHN에서 보호자가 "이것을 준비해 주세요"라고 적은 내용은 **원무과 뷰에 체크리스트로** 뜬다. 원무과가 **항목마다** 준비 완료를 누르면, **설정이 켜진 병원**에서는 원장님 뷰에도 "보호자님 준비 요청" 한 줄로 표시된다.

- **굿모닝펫(우리 병원)**: 꺼 둔다. 원장님은 진료에만 집중한다.
- **다른 병원 배포본**: 켜 둔다. 원무과 준비가 끝난 것만 보이므로 원장님이 준비 상태까지 신경 쓸 필요가 없다.
- 설정 위치: GCN 상단 **⚙️ 병원 설정**의 `원장님 뷰에 보호자 준비 요청 표시` (켜기/끄기). 기본값은 **켜기**이며, 굿모닝펫 배포본만 끔.
- 표시 내용은 **준비 완료된 요청만**: "보호자 요청 · 준비 완료 — 손발톱 봉돌이 3개" 처럼 짧게. 미완료 건은 원장님 뷰에 뜨지 않는다.

### 실제 구현 (2026-11-28 GCN)
- **데이터**: GHN의 '다시 필요해요'는 웹훅이 시트 `예약` **P열(보호자요청)**에 넣는다. GCN은 그 칸을 읽어 **쉼표·줄바꿈·제품 단위**로 항목을 나눈다(괄호 안의 `·`·`,`는 자르지 않음). 항목이 길면 `상세` 버튼으로 설명만 펼친다.
- **원무과 뷰**: 항목마다 체크박스 + 담당 이름 칸. 체크하면 **누가·언제** 했는지(`✅ 홍길동 · 11/28 18:36`) 남는다. 미완료가 있으면 기본 펼침, 다 끝나면 `N건 · 모두 완료`로 접힘.
- **설정 저장 순서**: ① 그 브라우저의 설정(토글) → ② 시트 `설정` 탭의 `원장님뷰_보호자준비`(켜기/끄기) → ③ 기본값 **켜기**. 그래서 다른 병원은 아무것도 안 해도 켜져 있고, 굿모닝펫은 시트에 `끄기` 한 줄로 둔다.
- **주의**: 체크는 각자 브라우저에 저장된다(원무과 2인 체제 기준). 다른 기기와 자동으로 맞춰지지는 않는다.

### 긴 목록은 접어 둔다 (GCN 공통)
- 보호자님 준비 요청·사전체크·선결제·원무과 준비·코멘트는 처음에 **한 줄 요약과 건수**만 보이고, 누르면 펼쳐진다. 기본은 접힘, **원무과 조치가 필요한 건**만 기본 펼침.
- 버튼 높이는 44px 이상(모바일), 펼친 상태는 **새로고침해도 유지**된다.


## 원칙
- 유형을 모르는 예약에는 **금식·금수 안내를 보내지 않는다.** 잘못 보내면 보호자가 밥을 굶긴다.
- 유형이 비어 있는 비율을 GCN 하루 요약에 숫자로 남긴다(예: "유형 미입력 3건"). 그래야 원무과 습관이 잡힌다.
